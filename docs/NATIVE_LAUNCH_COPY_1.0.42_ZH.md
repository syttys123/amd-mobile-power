## 事实口径

- 当前稳定本地包：`1.0.42`，源码 `927a1bbf74e78b061eafb6088e807f4fc5ff365b`。
- ZIP：795,340 bytes，SHA256
  `35384501e2cf4b5808ba8796d212fb4b7394d49455153e817fefed1c11b44998`。
- 唯一完整实机证据：MECHREVO WUJIE15 PRO / AMD Ryzen 7 8845HS。
- 默认只读；写入前必须阅读免责声明、操作须知并勾选确认。
- 三档快捷预设可编辑；简洁模式点预设立即应用，高级模式同样立即应用。
- 自动策略可分别设置电池和外接目标，也可选择仅电池。
- Windows 通常把 USB-C 充电宝和墙插都识别为外接电源，程序不能可靠区分两者。
- 固件可能压低 STAPM；界面分开显示请求目标、实时功耗和实际上限。
- 诊断导出不上报，不包含本地路径、账号、进程 ID、序列号或近期日志。
- 其他 AMD 世代仍是保守实验配置，不声明全型号通用。
- 宣传片使用 1.0.42 GUI 的隔离模拟数据，明确标注“模拟数据 · 未写硬件”；
  无声字幕审查版，不使用合成噪声配乐。

## GitHub Release 草稿

标题：

正文：

````markdown
## AMD Mobile Power 1.0.42

一个面向 AMD 轻薄本的开源 Windows 功耗面板。Rust GUI 负责界面和托盘，
C++ worker 负责硬件访问；默认只读，写入前需要明确确认，写入后自动回读。

### 主要功能

- 实时 STAPM、PPT Fast、PPT Slow、温度和供电状态。
- 简洁/高级模式、置顶、托盘和单实例唤醒。
- 三档可编辑快捷预设，点击即应用。
- 电池/外接自动策略，支持仅电池。
- 固件限制提示，区分目标值和实际生效上限。
- 脱敏诊断导出、便携 ZIP、安装/卸载与校验文件。

### 1.0.42 修复

- 区分观察到的供电线路、尝试应用的线路和成功应用的线路。
- 手动写入目标不再冒充自动策略目标。
- 维护脚本拒绝把旧的观察成功当成新写入成功。
- 晋升流程绑定 ZIP/源码身份和全部包内校验和，失败后可回滚。
- 安装器支持 `C:\RyzenAdj` 这类盘符直属目录。

### 已验证

- Rust GUI 74 项、probe 7 项、C++ 策略/清理/安全测试、格式与 Clippy。
- 可复现构建、隔离安装/卸载、托盘/任务栏/模式/写入控制回归。
- worker 卡死替换、DPI/短工作区夹具、公开材料脱敏和托管 Windows CI。
- 一台 8845HS 上的受控写入与回读。

### 安全边界

这不是“全 AMD 通用版”。其他机型请先运行只读诊断，确认平台能力后再从
小数值试用。不要关闭 Windows 安全防护来运行 WinRing0。充电宝通常按外接
电源处理。修改固件功耗限制存在稳定性与硬件风险，请自行判断并保留恢复路径。

项目地址：https://github.com/syttys123/amd-mobile-power
````
